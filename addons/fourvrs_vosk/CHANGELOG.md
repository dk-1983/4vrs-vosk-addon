# Changelog / История изменений

## 0.1.0

- First HA app: Vosk 0.3.45, Wyoming endpoint on port 10301.
- Preloaded selectable RU/EN model, persistent model storage and optional download.
- English/Russian configuration labels, bounded requests, transcript-free logs.
- No password grammar, approximate matching, door control or dialog in the app.

Первый выпуск: автономный Vosk с управлением через Supervisor, выбором модели,
сохранением моделей и настройками на русском и английском.
